# ♈ Horoscope App

A horoscope application built with **Next.js**, **TypeScript**, and **SCSS**.  
Users can select their zodiac sign and view its description, element, and other related details.

## Live Demo

You can check out the live version of the app at: [https://horoscope-sepia.vercel.app/](https://horoscope-sepia.vercel.app/)

## Features

- **Zodiac Sign Selection**: Select a zodiac sign to see its detailed information.
- **Icons**: Each zodiac sign has a unique icon.
- **Element and Dates**: Displays the element and date range for each zodiac sign.
- **Multi-language Support**: Currently supports Ukrainian names for zodiac signs.

## Technologies Used

- **Next.js**: React framework for server-side rendering and static site generation.
- **TypeScript**: For better code quality and type safety.
- **SCSS**: For styling the components and application.
